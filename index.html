찍어줄게 · iPhone 카메라 앱

개인정보처리방침

시행일: 2026년 10월 2일 · 최종 수정일: 2026년 10월 10일

찍어줄게는 사진을 기기 안에서 촬영·분석·선별하는 앱입니다. 개발자는 앱을 통해 사용자의 사진이나 개인정보를 수집하거나 외부 서버로 전송하지 않습니다.

1. 기기 안에서 처리하는 정보

카메라 프레임의 사람 위치, 신체 관절과 얼굴 영역을 분석해 구도를 안내하고 자동 촬영합니다. 촬영한 사진을 선별할 때 유사 장면, 선명도, 노출과 선택적인 얼굴 촬영 품질을 기기 안에서 분석합니다. 얼굴의 신원을 식별하는 기능은 없습니다. 분석 결과와 사진을 개발자에게 전송하지 않습니다.

촬영 원본, 남김·휴지통·저장 상태, 되돌리기 기록과 선택한 색감 설정은 앱 내부에 보관합니다. 색감은 사용자가 선택할 때만 기기 안에서 처리하며 촬영 원본을 덮어쓰지 않습니다. 음성 안내와 첫 실행 안내 여부 등 기기 설정도 기기에 저장합니다.

2. 사용 권한

  • 카메라: 사진 촬영과 화면 속 인원·구도 분석에 사용합니다.
  • 사진 추가: 사용자가 선택한 사진을 사진 앱에 저장할 때 요청합니다. 사진 앱의 전체 보관함을 읽는 권한은 요청하지 않습니다.

마이크, 연락처, 위치 권한은 요청하지 않습니다. 카메라 접근을 거절하면 촬영 기능을 사용할 수 없습니다. 사진 추가 권한을 거절해도 촬영한 사진은 앱 안에 남으며, 권한 허용 후 저장을 다시 시도할 수 있습니다. 권한은 iPhone의 설정에서 변경할 수 있습니다.

3. 보관과 삭제

촬영 원본과 분류·색감 기록은 앱의 저장 공간에 보관하며 기기 백업에서 제외하도록 설정합니다. 파일에는 iOS 데이터 보호를 적용합니다. 저장·공유용 보정 사본은 보호된 임시 공간에서 만들고 작업 완료 시 정리합니다. 중단된 작업의 임시 사본은 다음 앱 실행에서 정리합니다.

휴지통 사진은 직접 비우기 전까지 복원할 수 있습니다. ‘휴지통 비우기’를 확인하면 해당 앱 원본을 영구 삭제합니다. 사진 앱에 저장을 완료한 사진의 앱 내부 사본은 촬영 설정의 ‘사진 앱에 저장한 원본 정리’에서 삭제할 수 있습니다. 앱을 삭제하면 앱 안에만 보관한 사진과 분류 기록도 삭제됩니다. 앱 내부 삭제는 사진 앱에 이미 저장한 사진을 삭제하지 않습니다.

4. 저장과 공유

사용자가 선택할 때만 사진을 사진 앱에 저장하거나 시스템 공유 기능으로 전달합니다. 색감을 선택했다면 해당 설정으로 만든 사본을 전달하고, 원본 상태라면 촬영 파일을 그대로 전달합니다. 사진 앱에 저장한 사진의 iCloud 동기화는 사용자의 iPhone 설정을 따릅니다. 공유한 사진은 선택한 서비스의 개인정보처리방침을 따릅니다. 사진 앱의 사진을 삭제하려면 사진 앱에서 직접 삭제해야 합니다.

5. 광고·추적·제3자 제공

회원가입, 광고, 사용 분석 SDK, 기기 식별자를 이용한 추적, 개발자 서버와의 통신 기능이 없습니다. 개발자가 보관하는 사용자 데이터가 없으므로 개발자 서버의 데이터 삭제 요청 절차도 필요하지 않습니다. iOS 시스템 음성 안내와 시스템 기능은 Apple의 기기 설정을 따릅니다.
